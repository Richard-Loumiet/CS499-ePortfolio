Travlr Getaways Code Review

Before completing the enhancements for my CS 499 capstone, I performed a code review of the original Travlr Getaways full-stack application. The purpose of the review was to examine how the existing application worked, identify areas that could be improved, and explain the enhancements I planned to make in software engineering, algorithms and data structures, and databases.

The review focused on the existing Angular administrative interface, Express and REST API structure, MongoDB data models, authentication system, trip-management functionality, and the way information moved between the different layers of the application.

Existing Functionality

The original Travlr Getaways application already included a customer-facing website, an Angular administrative interface, REST API endpoints, MongoDB storage, user authentication using JSON Web Tokens, and trip-management functionality.

Reviewing the existing application helped establish a baseline before making changes and made it easier to identify which parts of the project could demonstrate additional growth.

Code Analysis

The review identified several areas where the original project could be improved. Authentication was present, but the application did not distinguish between standard users and administrators. The trip listing displayed all available data without searching, filtering, or sorting tools. The database also stored users and trips but did not include a reservation system that connected the two.

These findings became the basis for the three enhancements completed during the capstone.

Planned Enhancements

Software Design & Engineering

Improve authentication and authorization by adding user roles, role-based access control, protected API routes, and stronger administrative route protection.

Algorithms & Data Structures

Add searching, filtering, and sorting to the trip listing while evaluating the data structures, algorithms, and trade-offs involved.

Databases

Add a reservation system that connects users and trips while demonstrating database relationships, validation, indexing, and authenticated data access.
