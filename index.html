Featured Artifact: Travlr Getaways

Travlr Getaways is a full-stack web application originally created during CS 465. I selected the project as the primary artifact for my CS 499 capstone because it provided opportunities to demonstrate growth across all three required enhancement categories.

Software Design & Engineering

Authentication and authorization improvements including role-based access control, JWT role information, protected API routes, Angular route guards, and improved login handling.

View Enhancement

Algorithms & Data Structures

Search, filtering, and sorting functionality added to the trip-management interface using arrays, a Set, comparison operations, and data-processing logic.

View Enhancement

Databases

A reservation system was added using MongoDB and Mongoose, including user and trip relationships, validation, indexing, authenticated access, and reservation retrieval.
